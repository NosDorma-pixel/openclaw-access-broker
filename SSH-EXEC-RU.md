# SSH-команды — отдельное согласие

Optional tool `ssh_broker_exec` использует ssh2, закреплённый host key и пароль из vault. Он не присоединяется к чужому терминалу; SSH keys и agent forwarding не поддерживаются.

Владелец явно отмечает флажок разрешения SSH-команд в форме. По умолчанию он выключен. Поддельный параметр инструмента или сохранённый пароль в конфигурации не дают согласия. Повторный вход без флажка отзывает разрешение; действуют session/account и TTL. Дополнительно оператор разрешает сам tool в политике OpenClaw.

**Shell имеет права SSH-пользователя: allowedRoots ограничивает SFTP, но не команды. cwd — начальный каталог, не sandbox. Используйте отдельного непривилегированного пользователя.**

Команды неинтерактивные, stdin закрыт. На сервере нужны POSIX sh и GNU timeout. Таймаут 1–300 секунд, по умолчанию 120; общий вывод ограничен 256 KiB. Нет гарантии управления detached/nohup/setsid/background jobs. При потере транспорта сначала проверяйте результат, не повторяйте изменение вслепую.

Точный SSH-пароль маскируется в выводе, но это не универсальная очистка секретов. Вывод доступен агенту. Не печатайте env, токены, приватные ключи и секретные конфиги. Для команд с изменениями получите отдельное разрешение пользователя.

После работы удалите временный доступ. Удаление не меняет пароль на сервере и не отзывает ключи у провайдера. Перезапуск процесса теряет временные credentials.
